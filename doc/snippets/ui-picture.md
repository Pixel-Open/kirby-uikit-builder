# Snippet `ui/picture`

Minimal responsive `<picture>` renderer: srcset in the original format + WebP, generated by `PixelOpen\KirbyUikitBuilder\Image::sources()`. Used internally by the slider, carousel, card and media-object snippets, which manage their own wrappers (cover container, ratio, links).

For a full-featured render (ratio wrapper, lightbox, link, caption, lazy `uk-img`), use [`ui/image`](ui-image.md) instead.

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `image` | `Kirby\Cms\File` | `null` | Kirby file object: required, the snippet renders nothing otherwise |
| `sizes` | `string` | `'100vw'` | `sizes` attribute for the srcset, e.g. `'(min-width: 960px) 50vw, 100vw'` |
| `widths` | `array` | `Image::SRCSET_WIDTHS` | Srcset widths: pass `Image::COVER_WIDTHS` (640-1920) for full-bleed images |
| `alt` | `string\|null` | `null` | Alt text (falls back to `$image->alt()`) |
| `attrs` | `string` | `''` | Extra raw attributes for the `<img>` tag, e.g. `'uk-cover loading="lazy"'` |

## Behavior

Variants are generated at the requested widths, capped at the file's real width, in both the original format and WebP. The `src` fallback is the largest generated variant. SVG and GIF are served as-is (no variants). Native `loading` lazy loading is up to the caller via `attrs`, this snippet does not use `uk-img`.

The `<img>` tag carries the intrinsic `width`/`height` of the `src` variant (anti-CLS); do not pass them again through `attrs`.

## Example

```php
snippet('ui/picture', [
    'image'  => $slide->slide_image()->toFiles()->first(),
    'widths' => \PixelOpen\KirbyUikitBuilder\Image::COVER_WIDTHS,
    'attrs'  => 'uk-cover loading="lazy"',
]);
```

## Generated HTML

```html
<picture>
  <source type="image/webp" srcset="image-640x.webp 640w, image-1024x.webp 1024w, …" sizes="100vw">
  <img src="image-1920x.jpg" srcset="image-640x.jpg 640w, image-1024x.jpg 1024w, …" sizes="100vw" alt="…" uk-cover loading="lazy">
</picture>
```
