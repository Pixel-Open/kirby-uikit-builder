# Block: heading

Heading with semantic level, visual size, decorative style, color, and per-breakpoint alignment.

## Panel fields

### Content tab

| Field | Type | Description |
|-------|------|-------------|
| `level` | toggles | HTML level: `h1` · `h2` · `h3` · `h4` · `h5` · `h6` |
| `text` | writer (inline) | Heading text |

### Settings tab

| Field | Default | Description |
|-------|---------|-------------|
| `heading_size` | `""` | UIkit visual size: `h1`-`h6`, small, medium, large, xlarge, 2xlarge |
| `heading_style` | `""` | Decorative style: divider, bullet, line |
| `heading_color` | `""` | Color: muted, emphasis, primary, secondary, success, warning, danger |
| `text_align` | `""` | Alignment from the medium breakpoint (desktop) |
| `text_align_tablet` | `""` | Alignment from the small breakpoint (tablet) |
| `text_align_mobile` | `""` | Alignment below the small breakpoint (mobile) |
