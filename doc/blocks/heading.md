# Block `heading`

Heading with semantic level, visual size, decorative style, and color.

## Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `level` | select | `h2` | HTML level: `h1` · `h2` · `h3` · `h4` |
| `text` | text | - | Heading text |
| `size` | select | - | UIkit visual size: `small` · `medium` · `large` · `xlarge` · `2xlarge` |
| `style` | select | - | Decorative style: `divider` · `bullet` · `line` |
| `color` | select | - | Color: `muted` · `emphasis` · `success` · `warning` |
