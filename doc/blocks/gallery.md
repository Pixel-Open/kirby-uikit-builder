# Block `gallery`

Image gallery in a grid with UIkit lightbox.

## Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `files` | files | - | Images selected from page files |
| `grid` | select | `3` | Columns: 2 · 3 · 4 |
| `style` | select | `cropped` | `cropped` (uniform crop) · `masonry` (natural proportions) |
| `hover_style` | select | `dark` | Hover overlay: `white` · `dark` · none |
| `hover_opacity` | number | - | Overlay opacity on hover |
| `hover_icon` | select | `expand` | Center icon on hover: `plus` · `search` · `expand` · `eye` · `link` · none |
| `hover_caption` | toggle | `false` | Show alt text on hover |
