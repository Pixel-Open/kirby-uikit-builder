# Block `accordion`

UIkit accordion (`uk-accordion`).

## Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `items` | structure | - | List of items |
| `items.title` | text | - | Item title (always visible) |
| `items.content` | writer | - | Expanded content |
| `multiple` | toggle | `false` | Allow multiple items open at once |
| `first_open` | toggle | `false` | First item open by default |
